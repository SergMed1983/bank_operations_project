# Курсовая работа: Приложение для анализа банковских операций

## Описание
Приложение читает Excel-файл с транзакциями, генерирует JSON-ответы для веб-страниц, формирует отчёты и предоставляет сервисы.

## Задачи курсовой
- Веб-страница «Главная» (views.py)
- Сервис «Выгодные категории кешбэка» (services.py)
- Отчёт «Траты по категории» (reports.py)

## Установка и запуск
```bash
poetry install
```

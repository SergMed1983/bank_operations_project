# Курсовая работа: Приложение для анализа банковских операций

Приложение читает Excel-файл с транзакциями, генерирует JSON-ответы для веб-страниц, формирует отчёты и предоставляет сервисы.

## Реализованный функционал

### Веб-страница «Главная» (src/views.py)
- Приветствие по времени суток
- Информация по каждой карте (последние 4 цифры, сумма расходов, кешбэк)
- Топ-5 транзакций по сумме платежа
- Курсы валют (реальный API open.er-api.com)
- Цены акций S&P 500 (заглушка)

### Сервис «Выгодные категории кешбэка» (src/services.py)
- Анализ, сколько кешбэка можно заработать по каждой категории за месяц
- Исключение переводов и пополнений
- Кешбэк 1% от суммы трат

### Отчёт «Траты по категории» (src/reports.py)
- Траты по заданной категории за последние 3 месяца
- Декоратор save_report для сохранения результата в JSON-файл

### Утилиты (src/utils.py)
- Загрузка транзакций из Excel
- Преобразование даты в datetime

### Внешние API (src/api_client.py)
- get_currency_rates — реальные курсы валют
- get_stock_prices — заглушка с фиксированными ценами акций

## Установка и запуск

Запустите в терминале:

    poetry install
    poetry run python src/utils.py
